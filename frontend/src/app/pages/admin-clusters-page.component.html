  1. El servidor debe tener el backend y Mosquitto en ejecución.
  2. Usa una IP o DNS que la placa pueda alcanzar; no uses localhost ni el nombre Docker mosquitto en el firmware.
  3. Carga el firmware, completa Wi-Fi, credenciales MQTT y adapta las lecturas a los sensores conectados a la placa.
  4. La placa debe publicar cada 15 segundos en datacenter/ambiente. El estado cambiará cuando llegue la primera telemetría.

En el broker incluido, usa el puerto publicado por Docker (1883 por defecto). Para instrucciones completas de servidor, firewall, Mosquitto y firmware, consulta docs/conectar-dispositivo-mqtt.md.
